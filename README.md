# Birthday Wish Card ♡

A mobile-friendly birthday surprise website made with HTML, CSS and JavaScript.

## Personalise it
- Edit the message in `index.html`.
- Add `images/photo1.jpg` and `images/photo2.jpg` for your photos.
- Add `music.mp3` in the project root for optional background music.
- Keep file names and paths exactly the same (GitHub Pages is case-sensitive).

## Publish with GitHub Pages
1. Create a **Public** repository on GitHub.
2. Upload `index.html`, `README.md`, the `images` folder and optional `music.mp3`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for deployment and open the URL shown on the Pages screen. It usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Test the link on your own phone before sending it. Audio on iPhone starts only after a user taps the play button.
